# EchoBot – AI-based Earthquake Support Chatbot

**EchoBot** is an AI chatbot that provides emotional support and guidance during and after earthquakes. Built with **FastAPI** and **OpenAI GPT-3.5**, it helps users manage stress and panic through calm, empathetic responses and practical advice.

## Features
- Provides calm, reassuring messages to reduce stress during emergencies.
- Offers simple breathing exercises and grounding techniques.
- Maintains conversation history for seamless user interaction.
- Guides users on using app features without replacing official emergency services.
- Responsive web interface built with **Jinja2**, **CSS**, and **Bootstrap**.

## Technologies Used
- Python, FastAPI, OpenAI API
- Jinja2, HTML, CSS, Bootstrap
